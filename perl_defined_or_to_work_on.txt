In Perl, what is // meaning

ChatGPT said:
In Perl, // is the defined-or operator.

It returns the left-hand value if it is defined; otherwise, it returns the right-hand value.

my $name = undef;
my $display_name = $name // "Unknown";

print $display_name;  # Unknown

Difference between // and ||
This is an important distinction:

// checks whether a value is defined
|| checks whether a value is true
my $x = 0;

print $x // 10;   # 0
print $x || 10;   # 10

So // is useful when 0, "", or "0" are valid values and you only want a default for undef.

You can also use the defined-or assignment operator //=:

$name //= "Unknown";

This assigns "Unknown" to $name only if $name is currently undef.

Yes — same basic logic, but with one important difference: = makes it assign the result back to the variable.

Think of it this way:

Without =
$x || 10

means:

"Give me $x if it's true; otherwise give me 10."

It doesn't change $x.

my $x = 0;
my $y = $x || 10;

# $x is still 0
# $y is 10

With =
$x ||= 10

means:

"If $x is false, change $x to 10."

my $x = 0;

$x ||= 10;

# $x is now 10

Same idea with //:

$x // 10

means:

"Give me $x if it's defined; otherwise give me 10."

Whereas:

$x //= 10

means:

"If $x is undefined, change $x to 10."

The easiest mental model
||   → OR
||=  → OR + ASSIGN

//   → defined-OR
//=  → defined-OR + ASSIGN

So yes, ||= and //= use the same logic as || and //, respectively — they just store the resulting value back into the variable.
